将该文件书面化，使表述清晰、简洁、不口语化。
1. 删除口癖：自问自答的反问、句末语气词（对吧／好／嗯）、口头连接词（也就是说／由此看来／可以看到）、重复赘语、未写完的省略号；设问一律改写为陈述句。
2. 不改内容：不新增信息，不删减知识点，不改变观点与结论，只改表达方式。
3. 不改格式：标题层级、板块与列表、严格照原文的术语英文标注、`<mark>` 标注均保持原样。
4. 语言与原文一致，不做翻译；就地覆盖原文件；确实残缺、无法改写成完整句子的地方用 `<mark></mark>` 标出，不要编造补全。
完成后简要汇报所改的口癖类型，以及需要核对的位置。
